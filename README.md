# sitebiz

Находит в 2ГИС бизнесы **без сайта** по категории и городу, а потом по ссылке на
конкретный бизнес собирает всё его наполнение (услуги, режим, фото, реальные отзывы)
и выдаёт готовый промпт, по которому нейросеть делает ему современный сайт.

Схема целиком:

```
2ГИС ──► sitebiz scan ──► список лидов (CSV / HTML)
                              │
                              ▼
        ссылка на бизнес ──► sitebiz prompt ──► промпт с реальными данными
                                                      │
                                                      ▼
                                            вставляешь в чат с Claude
                                                      │
                                                      ▼
                                              готовый index.html
```

## Установка

Никакой. Нужен только Python 3.10+, внешних библиотек нет.

```bash
git clone <этот репозиторий>
cd sitebiz
python -m sitebiz --help
```

Работает на публичных API 2ГИС с демо-ключами. Если начнёт упираться в лимиты —
получи свой ключ на [dev.2gis.ru](https://dev.2gis.ru) и положи в окружение:

```bash
export TWOGIS_CATALOG_KEY=твой_ключ
```

## 1. Сканирование: кто без сайта

```bash
# найти id города (нужно редко, обычно хватает --city)
python -m sitebiz cities Казань

# основная команда
python -m sitebiz scan --city Казань -c "барбершоп" -n 300 --min-reviews 5 -o leads.html
```

Что получается на выходе:

```
СКОР  НАЗВАНИЕ            СТАТУС                 ★     ОТЗ  ТЕЛЕФОН
  89  Тартип              только соцсети: teleg  4.9   294  +79393686366
  85  Сакал               контактов сайта нет    4.8    61  +79673685574
  82  Барберлаб Контур    конструктор: taplink   5.0   441  +79050222509
```

Формат файла определяется расширением: `.html` (отчёт с поиском, сортировкой и
кнопкой «скопировать промпт»), `.csv` (открывается в Excel), `.json`, `.md`.

### Ключевые параметры

| Параметр | Что делает |
|---|---|
| `--city` | город, например `--city "Нижний Новгород"` |
| `-c, --category` | категория; можно повторять: `-c стоматология -c ортодонтия` |
| `-n, --limit` | сколько карточек просмотреть на категорию (по умолчанию 200) |
| `--status` | какие оставить: `none` (сайта нет), `weak` (соцсети/конструктор), `has` |
| `--min-reviews` | отсечь мёртвые точки: `--min-reviews 10` |
| `--min-score` | оставить только горячие лиды: `--min-score 70` |
| `--no-chains` | убрать сети (больше 3 филиалов) |
| `--all-branches` | показать все точки, а не одну на организацию |

### Как читается статус сайта

- **нет сайта** — в карточке вообще нет ссылки.
- **нет нормального сайта** — вместо сайта соцсети, `taplink`, бесплатный
  конструктор или ссылка на чужой каталог (`zoon`, `prodoctorov`, `avito`).
  Это тоже клиент, часто даже более тёплый: он уже понимает, что присутствие в сети нужно.
- **сайт есть** — свой домен, такие по умолчанию отфильтровываются.

### Скор лида (0–100)

Считается по формуле в `sitebiz/leads.py`: нет сайта `+45`, отзывы (логарифмом,
чтобы 1000 отзывов не забивали всё) `+25`, высокий рейтинг `+12`, наличие телефона,
почты, соцсетей и фото — плюсами, сеть филиалов — минусом. Смысл простой:
**живой бизнес с потоком клиентов, но без сайта** — это тот, кому сайт реально нужен
и у кого есть чем за него платить.

## 2. Промпт: сайт по ссылке

```bash
python -m sitebiz prompt https://2gis.ru/firm/70000001033848371 -o promo.md
```

Команда сама сходит в 2ГИС, вытащит услуги, цены из карточки, режим работы,
координаты, фото и до 25 реальных отзывов с ответами владельца, вклеит всё это
в шаблон `prompts/website_builder.md` и положит готовый текст в файл.
Дальше просто вставляешь этот текст в чат — на выходе цельный `index.html`.

Ссылки Яндекс.Карт тоже принимаются: Яндекс не отдаёт данные организации напрямую,
поэтому sitebiz находит этот же бизнес в 2ГИС по названию и координатам из ссылки
и предупреждает об этом — сверь, что совпало правильно.

Отдельно бриф без промпта:

```bash
python -m sitebiz brief <ссылка> --format json -o brief.json
python -m sitebiz brief <ссылка> --download-photos assets   # реальные фото на диск
```

## 3. Что дальше делать с этим

Порядок, в котором это превращается в деньги:

1. **Скан** по своему городу и 5–10 категориям, где средний чек высокий:
   стоматология, автосервис, барбершоп, ремонт квартир, кухни на заказ,
   юристы, груминг, детские центры.
2. **Отбор**: `--min-score 70 --min-reviews 10 --no-chains`. Это 20–40 контактов,
   а не 500 — по ним реально пройтись руками.
3. **Демо вперёд оплаты**: сгенерируй сайт по 3–5 лучшим лидам **до звонка**.
   Заливаешь на Netlify Drop (бесплатно, перетаскиванием), получаешь ссылку.
4. **Заход**: пишешь/звонишь и сразу даёшь ссылку на готовый сайт с их фото и
   их отзывами. Шаблон сообщения — в `prompts/outreach.md`.

### Приложение, бот или агент?

Сейчас это CLI-скрипт, и для старта это правильный выбор: ноль зависимостей,
запускается где угодно, легко менять под себя. Когда пойдёт поток —
самое полезное развитие в таком порядке:

1. **Telegram-бот** поверх этого же кода: `/scan Казань барбершоп` → присылает
   CSV, `/site <ссылка>` → присылает готовый сайт. Логика уже вся есть,
   боту останется только звать `sitebiz.cli`.
2. **Мини-CRM**: сохранять лиды в SQLite и помечать «написал / ответил / продал»,
   чтобы не долбиться в одних и тех же по второму кругу.
3. **Автогенерация демо**: цикл «топ-20 лидов → 20 сайтов → 20 ссылок» пачкой.

## Структура репозитория

```
sitebiz/
  cli.py       команды scan / brief / prompt / cities
  twogis.py    клиент API 2ГИС: города, поиск, карточка, отзывы
  website.py   определение «есть ли нормальный сайт»
  leads.py     нормализация карточки и скоринг лида
  brief.py     сбор контент-брифа под генерацию сайта
  links.py     разбор ссылок 2ГИС и Яндекс.Карт
  export.py    выгрузка в CSV / JSON / Markdown / HTML-отчёт
prompts/
  website_builder.md  главный промпт: бриф → современный сайт
  outreach.md         промпт для первого сообщения владельцу
```

## Важно

Инструмент читает только те данные, которые 2ГИС и так показывает публично
на своём сайте, и делает это медленно (пауза между запросами настраивается
через `SITEBIZ_THROTTLE`). Не превращай его в массовую рассылку: холодный спам
по всем 500 контактам сразу убивает конверсию быстрее, чем плохой сайт.
Персональные данные из отзывов (имена авторов) публикуй на сайте клиента
в том же виде, в каком они уже опубликованы в 2ГИС, и убирай по первой просьбе.
